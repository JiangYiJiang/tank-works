## 1. 已完成

按开发顺序，每一项都附可复现的验证方式。断言数会随代码变，以 `npm run check` 的输出为准。

### 1.1 设计局物理模型（第 1 步）✅

- 18 车体 / 6 装甲材料 / 19 火炮 / 17 发动机 / 18 悬挂 / 12 辅助套件
- 七步管线：几何 → 乘员 → 质量（迭代 4 次）→ 防护 → 弹道 → 机动 → 适应 → 评分 → 成本 → 缺陷
- 19 辆历史车全部落在门限内

**验证**：`npm run design` → 装甲 1.7% / 穿深 11.3% / 越野 12.6% / 适应 26.2%（仅报告），19/19 通过，`exit 0`

### 1.2 设计局界面（第 2 步）✅

- 六槽位 + 连续滑条（厚度、倾角）+ 样车库
- 四维条、14 项物理量、**耦合与代价四条链**、成本四项、缺陷列表、同期对比
- 弹道面板：5 个距离点柱状图 + 4 档倾角 + 一句话解释 + 「打得穿/打不穿」自检

**验证**：`npm run smoke:tank` → **28 项断言**（含换弹种后 5 个距离点数值相同、长杆弹 2km 保持率高于被帽弹、文案分支正确）

### 1.3 时钟与事件系统（第 3 步）✅

**验证**：`npm run clock` → **26 项断言**；整局快进亚毫秒级（本机 0.8 ms）

### 1.4 研发局数据与节奏（第 4 步前半）✅

## 2. 待完成

按依赖顺序排列。编号（P0-1、P2-14……）是稳定标识，文档别处引用这些编号。

### P0：把四个局接成一条闭环

| # | 功能 | 依赖 | 为什么必须 |
|---|---|---|---|
| 1 | **制造局接进主循环** | 时钟 | 现在它是独立页，不读全局状态，等于一个 demo |
| 2 | **游说局（订单 + 推销）** | 制造局产出、设计局型号 | 没有收入侧，整个经济闭环不成立 |
| 3 | **经济尺度统一重定** | 游说局 | 尺度由收入决定，收入还没有（现状：T-34 单台 ¥550,310，开局只有 ¥500,000） |
| 4 | **主游戏状态扩展** | 上面三项 | `GameState` 目前只有 cash/day/log，要装下产线、库存、订单、已掌握技术 |
| 5 | **存档版本迁移** | 4 | `STATE_VERSION` 要涨到 3+，老存档要能读 |

**关键风险**：第 1–4 项不能分开做。制造局接进主循环的那一刻，就必须同时有「产出往哪去」（游说局）和「钱从哪来」（订单），否则玩家会看到一个永远亏钱的厂子。

## 3. 已知问题与技术债

### 3.1 会直接影响玩法的

| # | 问题 | 现状 | 影响 / 下一步 |
|---|---|---|---|
| T1 | **技术 `fn` 未接线** | `tech.ts` 的 `fn` 只被研发局检视器读取（`research.ts`），设计局 `build.ts` 直接用 `TUNING` | 159 条技术对造车的影响目前为 0；这是 P2-14 |
| T2 | **抗破（CE）只算不判** | `armor.ts` 算出 `hullCe / turretCe`，`build.ts` 只把 `hull / turret / side` 带进 `Tank` | 评分、界面、击穿判定都没有抗破；复合装甲的 `ce` 优势等于不存在（P2-21） |
| T3 | **破甲弹拿 KE 等效判定** | 设计局自检把 2km 视线穿深与 `armorFront`（抗穿）比 | 若将来接订单，破甲弹会按「均质钢」逻辑打复合装甲，需要改成 CE 口径 |
| T4 | **部件全解锁** | 设计局下拉直接铺全表 | 开局就能选 NERA / 滑膛炮；等 P2-15 |
| T5 | **`ammo.pen.1` 卡在边界** | `year=1941` 但 `months=0 / cost=0` | 既不算开局自带（判据是 `year<=1915 && months===0`），也永远研发不到；`tech-budget` 的 starting 因此印 35 而不是 34。补约 10 月 / ¥90k 即可，但会改动节奏表，需一起复核 |
| T6 | **多线混产回款算错** | `manufacture.ts` 用 `factory.lines[0]` 的单价 × 全部产量 | 两条线造不同车时，回款按第一条线定价；接 P0-1 时顺手改成按线计价 |
| T7 | **升级维护费未接线** | `SLOT_UPGRADES / SPEED_UPGRADES` 的 `upkeep` 字段没人读；`research.ts` 只算 `3,500 × 通胀 × 槽数` | 扩张成本被低估；DESIGN §7.6 已注明 |
| T8 | **制造局未接主循环** | 独立页、占位回款 1.35×、60M 试算资金、手动推进 | 这是 P0-1；在它前面挡着的是「没有收入侧」 |
| T9 | **经济尺度未定** | T-34 ¥550,310 / 虎王 ¥1,499,003 / M1A1 ¥6,256,140；开局 ¥500,000 | 等游说局给出收入侧再定；DESIGN §10 有三个方案 |
| T10 | **躺平三十年几乎不亏** | 1945 才开工仍拿 143/159，只比满配少 5 条 | 单看研发确实如此；真正的闸门必须是现金流 |
| T11 | **机动只有越野速度一个轴** | 虎王 8.9 hp/t 仍拿 4095 分 | 加吨功率/行程会破坏全部校准，需要重标 |
| T12 | **研发进度只有「完成 / 未完成」** | 没有「投了 3 个月想放弃」的中断与沉没成本 | 现在研发局是读图工具，等接了主循环再补 |
