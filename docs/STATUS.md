### 1.2 设计局界面（第 2 步）✅

- 六槽位 + 连续滑条（厚度、倾角）+ 样车库

**验证**：`npm run smoke:tank` → **33 项断言**（含换弹种后 5 个距离点数值相同、长杆弹 2km 保持率高于被帽弹、文案分支正确、「采用此设计」写出交接）

### 1.3 时钟与事件系统（第 3 步）✅

- 28,124 天连续时间，四档速度，rAF + 定时器双驱动，切后台冻结

**验证**：`npm run clock` → **26 项断言**；整局快进亚毫秒级（本机 0.8 ms）

### 1.4 研发局数据与节奏（第 4 步前半）✅

- 159 条技术 / 65 梯子 / 7 泳道 / 34 条开局自带（还有 11 条 1992 年后的终局清单）

**验证**：`npm run tech` → 满配 4,077 槽月 / 3,500 需求 / 86% 利用率；三条规定全部满足，`exit 0`

### 1.5 研发局界面（第 4 步后半）✅

- 1912–1991 时间轴，7 条泳道，方块按年份定位并自动叠行
- 四种状态、超前倍率、今天竖线、落后年数
- 检视器：「今年开工实际要付」+ 前置 + 效果 + 系数

**验证**：`npm run smoke:research` → **27 项断言**（含同子行无重叠、竖线位置、超前倍率 ×13.04）

### 1.6 弹道两轴（第 5 步前插）✅

- 距离衰减 `keep(d) = k2k^((d-500)/1500)`，8 种弹各一条曲线
- 倾角响应 `cos(θ)^s`，s 从 0.85（被帽）到 1.20（长杆）到 0（破甲）

**验证**：`npm run ballistics` → 19 辆车表 + 8 条衰减曲线 + 4 档倾角表

### 1.7 制造局模型（第 5 步前半）✅

- 产线状态机（running / idle / retooling / starved）
- Wright 学习曲线：第 100 台 = 34%，地板 0.28（约第 228 台触底）
- 按材质分仓、14 天采购提前期、容量上限、超容丢弃
- 开工费 / 停工省一半 / 换型 30 天 + 熟练度 ×0.35

**验证**：`npm run factory` → 7 辆车三年产量（FT-17 3,944 / 虎王 686 / M1A1 1,013），学习曲线自检 34.0%

### 1.8 制造局界面（第 5 步后半）✅

- 产线卡（六格数据、人数滑条、班次、换型）+ 新建产线（可多条线）
- 仓库卡、学习曲线卡、产量卡、记录卡
- 手动推进 +7 / +30 / +90 天 / +1 年
- 它现在是**独立试算页**：60M 试算资金、占位回款；**主循环 `game.html` 用的是同一套模型**（见 1.10）

**验证**：`npm run smoke:mf` → **21 项断言**（已接入 `npm run check`）

### 1.9 经济闭环 M1 ✅

- 招标：每个时代三档标（4 / 8 / 16 台），门槛 = 同期参照车四维 × 70%、总分 × 55%
- 接单：产品必须过门槛；首批备料现货（最多 60% 现金）
- 排产：200 人 × 1 班，每天扣工资、出车、交付、回款；学习曲线照旧
- 逾期单价 ×70%；现金 < 0 破产；交完自动重新招标
- 产品按年代解锁（当前年份 + 2 年），换产品在下次接单时换型、熟练度 ×0.35

**验证**：`npm run economy` → **42 项断言**；`npm run smoke:game` → **67 项断言**

### 1.10 设计局 → 主循环 ✅

- 设计局右上角「采用此设计」：把六槽位设计 + 型号名写进 `localStorage`（`tank-works.design.v1`）
- 主循环「导入设计局的车」：读回设计、校验能不能算、按年代闸门放行，之后就是本厂产品
- 年代闸门：`designYear = max(车体/炮/发动机/悬挂/辅助/材料年代)`，必须 ≤ 当前年份 + 2
- 产品身份按制造参数比，不按名字：改名字不算换型，改参数才掉熟练度
- 设计局加了型号名输入框；采用后给回执

**验证**：`npm run smoke:tank` + `smoke:game` + `economy`（设计年代、超前拦截、导入后存档）

### 1.11 研发局接进游戏 ✅

- `GameState.research`：已掌握技术（ladder → tier）、在研项目、槽位/速度升级
- 开局掌握 34 条（每条梯子最高开局代）；一条梯子同时只能研一项，项目占科研槽
- 项目按天推进 `days / 30.44 × 速度 × 时代强度` 槽月；开工付研发费，完成时解锁
- 槽位/速度升级按年份购买，维护费只在有在研项目时扣（M1 简化）
- **零件闸门**：每个板块 `boardYear = max(已掌握代 year, 1915)`，零件 `era ≤ boardYear + 2`
- **性能闸门**：倾角默认 20° / 口径 57 / 倍径 30 / 装药 0.60 / pike；`designCheck()` 统一判断
- 修正 `ammo.pen.1`：补 10 月 / ¥90k，前置接 `ammo.apcr.1`，整条弹芯梯子现在能研发
- 科技完成会自动暂停，提示「选下一项」

**验证**：`npm run research` → **32 项断言**；`npm run smoke:game` → 研发面板/开工/完成/存档
